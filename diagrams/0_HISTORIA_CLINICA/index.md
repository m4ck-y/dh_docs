# Historia clínica — Índice Mermaid

Conversión tab por tab del drawio `0_DEMO_HISTORIA_CLINICA.drawio`
(7 páginas) a archivos **Mermaid** (`.mmd`) individuales en `snake_case`.

| Página (tab) | Archivo | Contenido |
|---|---|---|
| A - REGISTRO | `registro.mmd` | Datos del tutor/responsable, datos generales, contacto de emergencia. |
| B - ANTECEDENTES HEREDOFAMILIARES | `antecedentes_heredofamiliares.mmd` | Familiar + categoría de salud + enfermedad. |
| C - APNP | `apnp.mmd` | Vivienda, higiene, hábitos, sueño, actividad física, trabajo. |
| D - ANTECEDENTES PP | `antecedentes_pp.mmd` | Tabaco/vape/análisis, alcohol, drogas, alergias, cirugías, transfusiones, lesiones, hospitalización. |
| E - PADECIMIENTO ACTUAL | `padecimiento_actual.mmd` | Motivo de consulta y caracterización del síntoma. |
| ANEXO C | `anexo_c.mmd` | Rúbrica de activación condición → cuestionario (Psicología y Nutrición). |
| ANEXO D | `anexo_d.mmd` | Derivación a cuestionarios de Psicología según respuestas. |

Estos son formularios estructurales (no instrumentos psicométricos), por lo que
no llevan archivo de revisión `-review.md`.
