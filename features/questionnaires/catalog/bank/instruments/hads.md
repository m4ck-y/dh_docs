# HADS

**Nombre:** Escala de Ansiedad y Depresión Hospitalaria

**¿Qué evalúa?:** Ansiedad y depresión en pacientes con visitas constantes al hospital

**Grupo etario:** ≥14 años

**Referencia:** [Escala de Ansiedad y Depresión Hospitalaria (HADS)](https://www.redalyc.org/pdf/1339/133930525004.pdf)

**Tiempo aplicativo:** ≤15 minutos

**Número de ítems:** 14

**CIE-11:** 6A7, 6B0

**Categoría:** Bienestar mental

---

## Instrucciones

Lea cada pregunta y seleccione la respuesta que usted considere que coincide con su propio estado emocional en la última semana. No es necesario que piense mucho tiempo cada respuesta; en este cuestionario las respuestas espontáneas tienen más valor que las que se piensan mucho.

---

## Preguntas

**Subescala A — Ansiedad**

A.1. Me siento tenso/a o nervioso/a
    - Nunca = 0
    - De vez en cuando = 1
    - Gran parte del día = 2
    - Casi todo el día = 3
A.2. Siento una especie de temor como si algo malo fuera a suceder
    - No siento nada de eso = 0
    - Sí, pero no me preocupa = 1
    - Sí, pero no muy intenso = 2
    - Sí, y muy intenso = 3
A.3. Tengo la cabeza llena de preocupaciones
    - Nunca = 0
    - De vez en cuando = 1
    - Gran parte del día = 2
    - Casi todo el día = 3
A.4. Soy capaz de permanecer sentado/a tranquilo/a y relajado/a
    - Siempre = 0
    - A menudo = 1
    - Raras veces = 2
    - Nunca = 3
A.5. Experimento una desagradable sensación de «nervios y hormigueos» en el estómago
    - Nunca = 0
    - Sólo en algunas ocasiones = 1
    - A menudo = 2
    - Muy a menudo = 3
A.6. Me siento inquieto/a como si no pudiera parar de moverme
    - En absoluto = 0
    - No mucho = 1
    - Bastante = 2
    - Realmente mucho = 3
A.7. Experimento de repente sensaciones de gran angustia o temor
    - Nunca = 0
    - Raramente = 1
    - Con cierta frecuencia = 2
    - Muy a menudo = 3

**Subescala D — Depresión**

D.1. Sigo disfrutando de las cosas como siempre
    - Ciertamente, igual que antes = 0
    - No tanto como antes = 1
    - Solamente un poco = 2
    - Ya no disfruto con nada = 3
D.2. Soy capaz de reírme y ver el lado gracioso de las cosas
    - Igual que siempre = 0
    - Actualmente, algo menos = 1
    - Actualmente, mucho menos = 2
    - Actualmente, en absoluto = 3
D.3. Me siento alegre
    - Gran parte del día = 0
    - En algunas ocasiones = 1
    - Muy pocas veces = 2
    - Nunca = 3
D.4. Me siento lento/a y torpe
    - Nunca = 0
    - A veces = 1
    - A menudo = 2
    - Gran parte del día = 3
D.5. He perdido el interés por mi aspecto personal
    - Me cuido como siempre lo he hecho = 0
    - Es posible que no me cuide como debiera = 1
    - No me cuido como debería hacerlo = 2
    - Completamente = 3
D.6. Espero las cosas con ilusión
    - Como siempre = 0
    - Algo menos que antes = 1
    - Mucho menos que antes = 2
    - En absoluto = 3
D.7. Soy capaz de disfrutar con un buen libro o con un buen programa de radio o televisión
    - A menudo = 0
    - Algunas veces = 1
    - Pocas veces = 2
    - Casi nunca = 3

---

## Interpretación

Cada subescala se puntúa por separado (Ansiedad A / Depresión D):

| Puntuación | Interpretación |
|---|---|
| 0-7 | Normalidad |
| 8-10 | Probable (ansiedad / depresión) |
| 11-21 | Caso de (ansiedad / depresión) |
